# Thousandfold

A browser idle RPG: gather, craft, fight, raise pets and climb the leaderboards.

**Play:** https://thah3b.github.io/thousandfold/

## For developers

- `index.html` is the whole game in one file, built from `src/` with `node build.js`.
- `supabase/` holds the server: schema, security rules, validation and setup notes.
- Patch notes live in `src/patchnotes.js` and show in the game's Settings tab.
